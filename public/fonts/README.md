# Fuentes de marca

Los archivos `jost-latin.woff2` y `montserrat-latin.woff2` son las variantes
latinas variables que Next.js genera para las familias Jost y Montserrat
declaradas en `src/app/layout.tsx`. Se copian al árbol público para que el
Configurador estático use las mismas fuentes sin depender de Google Fonts en
tiempo de ejecución.

Ambas familias se distribuyen bajo SIL Open Font License.
